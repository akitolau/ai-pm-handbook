# AI 产品经理 · 面试作战手册

一个**单文件、零依赖、断网可用**的面试准备手册。整本手册只有一个 `index.html`，不加载任何外部资源，双击即可打开，也可以直接放到手机上翻。

> 在线看：<https://akitolau.github.io/ai-pm-handbook/>

---

## 里面有什么

32 页，按真实面试的出场顺序排成六个板块：

| 板块 | 内容 |
|---|---|
| **S0 开场** | 封面 / 一页纸速记 / 面试复盘 |
| **S1 我是谁** | 自我介绍三版（含动机、岗位理解、核心技能匹配）· 通用问题 · 项目经历总览 · 三个项目深挖 · MCP / Tool Calling / Workflow |
| **S2 题库** | 日常 AI（含主流产品用户心智）· 产品设计题 · 数据 PM 十问 · 自设计 AI 产品 |
| **S3 技术底子** | AI 技术认知 · RAG 深挖 · 模型选型 · 千问模型全景 · 项目分阶段拆解 · 前端/后端/终端 |
| **S4 评测** | 打分实战 · 评测优势 · 评测岗画像 · 金融评测集构建 · 测试集与验收集怎么搭 |
| **S5 收尾** | 行业认知 · 商业化 · HR 面 · 反问环节 · 八大误区清单 |

## 怎么用

- **翻页**：`←` `→`、空格、`PageUp` / `PageDown`、`Home` / `End`
- **跳页**：顶部页签，或直接输入数字键
- **分区跳转**：顶部六个板块按钮
- **全站搜索**：`/` 或 `⌘K`，输入关键词（支持中文），`↑` `↓` 选择，回车直达
- **术语浮窗**：正文里带蓝色虚线的词，鼠标悬停看一句话解释
- **深挖专题**：带**双下划线 + ◆** 的术语是重点考察项，悬停后点「查看完整拆解」，会弹出辨析表、实现环节、关联案例，并可一键跳到对应页面
- **手机**：左右滑动翻页

## 设计说明

- 单文件构建：`index.html` 内含全部样式、脚本、图例与术语词典，无 CDN、无字体外链、无埋点
- 三档视口（1440 / 1280 / 390）已做溢出与排版校验
- 术语与知识点采用「长词优先」匹配，避免短词截断长词

## 关于内容

手册中的项目数据均按真实口径书写，测算类数字明确标注为「参考测算，非实测」。涉及企业内部信息的部分已做脱敏处理。
